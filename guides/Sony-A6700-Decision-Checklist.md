# Sony A6700 — Decisions Before You Start

Before opening Claude and configuring the camera, you and your uncle need to make these decisions together. Grab a coffee, go through this list, and write down your answers. This should take about 30 minutes.

---

## Decision 1: Your Lenses

You currently have:
- **Sony E 70-350mm f/4.5-6.3 G OSS** — telephoto zoom (wildlife, birds, distant subjects)

**What you're missing:**
The 70-350mm cannot do wide-angle (landscapes, streets, interiors) or get close to small subjects (macro). You have a gap from 0 to 70mm.

**Recommended first addition:**
- **Sony E 18-135mm f/3.5-5.6 OSS** (~$550) — covers everything from wide to medium telephoto. With this + the 70-350mm you'd have 18mm to 350mm covered.

| Question | Your Answer |
|----------|-------------|
| Do you have any other lenses? | |
| Are you willing to buy the 18-135mm before starting? | |
| If not now, when? (We can configure modes for it already) | |

**Why this matters:** If you only have the 70-350mm, modes like Street, Landscape, and Portrait will be limited. We can still configure them, but the results will be much better with a wider lens.

---

## Decision 2: The 3 Main Scenarios (Mode Dial — MR1, MR2, MR3)

The Sony A6700 has **3 positions on the mode dial** for saved configurations. These are your most-used scenarios — one click and you're shooting. Choose wisely.

**Suggested assignment:**

| Dial Position | Suggested Scenario | Lens | Why on dial? |
|---------------|-------------------|------|--------------|
| **MR1** | Wildlife / Action | 70-350mm | Your primary interest. Must be instant |
| **MR2** | Birds in Flight | 70-350mm | Need to switch fast when a bird takes off |
| **MR3** | Street / General | 18-135mm (or 70-350mm for now) | Your "grab and go" mode |

| Question | Your Answer |
|----------|-------------|
| Do you agree with these 3? | |
| Would you swap any? (e.g., Landscape instead of BIF?) | |
| Is there a scenario you shoot MORE than these? | |

**Think about it this way:** When you're in the field and an animal appears, you need MR1 in less than 1 second. When a bird flies, you switch to MR2 in 1 second. These must be on the dial.

---

## Decision 3: The 4 Extra Scenarios (Memory Card — M1, M2, M3, M4)

These are recalled from the menu (Menu → recall). Slightly slower access (3-5 seconds), so they're for situations where you have time to prepare.

**Suggested assignment:**

| Card Slot | Suggested Scenario | Lens | Notes |
|-----------|-------------------|------|-------|
| **M1** | Landscape | 18-135mm wide end | Tripod or handheld, deep DoF |
| **M2** | Portrait / People | 18-135mm or 70-350mm at 70mm | Face/Eye detection ON |
| **M3** | Macro / Close-Up | Future macro lens | Placeholder — skip for now |
| **M4** | Night / Low Light | Any lens, wide open | Handheld night, stars, etc. |

| Question | Your Answer |
|----------|-------------|
| Do you agree with these 4? | |
| Do you want to replace Macro with something else for now? | |
| Any scenario you'd add? (Video? Indoor events? Sports?) | |

**Important:** M1–M4 are stored on the SD card. If you format the card, you lose them. Always keep a backup in your JSON file — you can re-program them in 5 minutes.

## Decision 4: Wildlife Settings — Your Starting Point

Since wildlife is your main interest, let's get specific:

| Question | Your Answer |
|----------|-------------|
| What animals do you photograph most? (birds, mammals, reptiles?) | |
| Perched/static or moving/flying? | |
| What distance typically? (5m, 20m, 50m+?) | |
| Do you shoot from hides/blinds or walking? | |
| Morning light or all day? | |

**Why this matters:** A photographer shooting perched birds at 10m needs different settings than someone shooting running mammals at 50m. This drives shutter speed, AF area, and burst speed choices.

## Decision 6: Image Format

| Option | Pros | Cons |
|--------|------|------|
| **JPEG only** | Small files, ready to share | Can't fix exposure/WB mistakes later |
| **RAW only** | Maximum editing flexibility | Must process every photo, large files |
| **RAW + JPEG** | Best of both — share JPEG, edit RAW when needed | Uses more card space |

| Question | Your Answer |
|----------|-------------|
| Your choice? | |
| Do you edit photos? (Lightroom, Snapseed, etc.) | |
| If not, are you interested in learning? | |

**Recommendation:** If you don't edit yet, start with **RAW + JPEG Fine**. Use the JPEGs now, and when you learn editing, the RAWs will be waiting.

## Decision 7: Budget for Accessories

Beyond lenses, some accessories make a big difference:

| Accessory | Priority | Approx. Cost | Why |

| Fast SD card (UHS-II, 128GB+) | **Essential** | $30-50 | Burst shooting fills cards fast |

| Extra battery | High | $30-50 | A6700 battery is decent but a spare is insurance |

| Question | Your Answer |

**If you answered "no" to the first two:** That's totally fine. Before configuring modes, spend 30 minutes with Claude asking it to explain the exposure triangle and depth of field. Understanding these two concepts makes EVERYTHING else make sense.
