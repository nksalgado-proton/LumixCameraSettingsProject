Camera Configuration Update — Step-by-Step Checklist

Date: 2026-04-01 Purpose: Apply field-test learnings + Live View Boost + sleep/display tweaks Time estimate: Pre-work ~2 min · MkI ~10 min · MkII ~22 min

Menu paths reference

G9 MkI

  • Sleep Mode: MENU → Setup (wrench) → Power Save Mode → Sleep Mode
  • Fn button assignment: MENU → Custom → Operation → Fn Button Set → (select button)
  • Live View Boost: MENU → Custom → Monitor/Display → Live View Boost
  • Show/Hide Layout: MENU → Custom → Monitor/Display → LVF/Monitor Disp. Set (may not have Black Screen toggle — if not found, skip that step)
  • Save mode: MENU → Cust.Set Mem. → (pick slot)

G9 MkII

  • Sleep Mode: MENU → Setup (wrench) → Power Save Mode → Sleep Mode
  • Fn button assignment: MENU → Custom → Operation → Fn Button Set → (select button)
  • Live View Boost: MENU → Custom → Monitor/Display → Live View Boost
  • Show/Hide Layout: MENU → Custom → Monitor/Display → Show/Hide Monitor Layout
  • Save mode: MENU → Save to Custom Mode → (pick slot)

The G9 MkI is currently set to JPEG only. Change to RAW+JPEG Fine for better macro/wildlife flexibility in post.

  • [ ] 18.1. On G9 MkI, press Q.MENU → select Quality → RAW+JPEG Fine
  • [ ] 18.2. Verify on each mode (rotate through C1-C3-3) that Quality stays RAW+JPEG
